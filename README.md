# 🎓 AI Learning Roadmap Generator

An AI-powered personalized learning roadmap generator that creates practical and structured learning plans based on a user's field, skill level, available learning duration, and daily study time.

## 🚀 Features

- 🤖 AI-powered personalized learning roadmaps
- 📚 Beginner, Intermediate, and Advanced skill levels
- ⏱️ Custom learning duration
- 🕐 Daily study hours customization
- 🗺️ Learning roadmap divided into phases
- 💻 Practical project for each phase
- 🏆 Final capstone project
- ✅ Interactive learning checklist
- 📊 Automatic learning progress tracking
- 🔄 Progress reset functionality
- 🌐 Gradio-based user interface

## 🛠️ Technologies Used

- Python
- Gradio
- Groq API
- Large Language Model (LLM)
- JSON

## ⚙️ How It Works

1. Enter the domain or field you want to learn.
2. Select your current skill level.
3. Enter your desired learning duration.
4. Enter the number of hours you can study per day.
5. Click **Generate Roadmap**.
6. The AI generates a personalized learning roadmap.
7. Complete topics using the interactive checklist.
8. Track your learning progress using the progress bar.
